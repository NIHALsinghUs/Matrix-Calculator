# Matrix Master

A simple Matrix Calculator project built using Python and NumPy.

## Features

* Matrix Addition
* Matrix Subtraction
* Matrix Multiplication
* Matrix Transpose
* Dynamic Matrix Input
* Command Line Interface

## Technologies Used

* Python
* NumPy

## How It Works

The program takes matrix input from the user and performs different matrix operations based on the selected option.

## Operations Supported

### Addition

Adds two matrices of the same order.

### Subtraction

Subtracts one matrix from another.

### Multiplication

Performs matrix multiplication using NumPy.

### Transpose

Converts rows into columns and columns into rows.

## Learning Concepts

This project helps beginners practice:

* Python loops
* Lists
* Conditional statements
* NumPy arrays
* Matrix operations
